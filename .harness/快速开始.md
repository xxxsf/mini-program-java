# Harness 快速开始指南

这是一个 5 分钟快速入门指南，帮助您快速启动 Harness CI/CD。

## 🚀 快速开始 (5 步)

### 第 1 步：注册 Harness 账户 (2 分钟)

1. 访问 https://app.harness.io/
2. 使用 GitHub 账号登录 (推荐)
3. 创建新项目：`invoice-tool`

### 第 2 步：配置连接器 (5 分钟)

#### A. GitHub 连接器
1. 进入 **Connectors** → **New Connector**
2. 选择 **GitHub**
3. 使用 GitHub App 授权
4. 命名为：`github-connector`

#### B. Docker Hub 连接器
1. 创建新的 **Docker Registry** 连接器
2. 输入 Docker Hub 用户名和访问令牌
3. 命名为：`docker-hub-connector`

#### C. Kubernetes 连接器
1. 创建新的 **Kubernetes Cluster** 连接器
2. 上传 kubeconfig 文件
3. 命名为：`kubernetes-connector`

### 第 3 步：导入管道配置 (2 分钟)

1. 进入 **Pipelines** → **Create Pipeline**
2. 选择 **Import from Git Repository**
3. 选择您的 `github-connector`
4. 选择仓库 `mini-program-java`
5. 文件路径：`.harness/pipeline.yaml`
6. 点击 **Import**

### 第 4 步：更新配置 (3 分钟)

编辑导入的管道，替换连接器引用：

```yaml
# 找到并替换这些值
connectorRef: account.github-connector      # → account.github-connector
connectorRef: account.docker-hub-connector  # → account.docker-hub-connector  
connectorRef: account.kubernetes-connector  # → account.kubernetes-connector

# 更新 Docker 镜像路径
your-dockerhub-username/invoicetool:latest  # → your-username/invoicetool:latest
```

### 第 5 步：运行管道 (1 分钟)

1. 点击 **Run Pipeline**
2. 选择分支：`main`
3. 点击 **Run**
4. 等待执行完成 (大约 5-10 分钟)

## ✅ 验证部署

```bash
# 检查 Kubernetes 部署
kubectl get pods -l app=invoicetool

# 查看服务
kubectl get service invoicetool-service

# 获取访问地址
kubectl get service invoicetool-service -o wide
```

## 🔧 常见问题快速解决

### 问题：连接器测试失败
**解决**：检查网络连接和凭据是否正确

### 问题：构建失败
**解决**：检查 Java 版本 (需要 Java 17) 和 Maven 配置

### 问题：Docker 推送失败
**解决**：验证 Docker Hub 用户名和令牌

### 问题：Kubernetes 部署失败
**解决**：检查 kubeconfig 和集群权限
