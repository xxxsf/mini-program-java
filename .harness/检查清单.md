## 🆘 常见问题快速检查

如果遇到问题，按以下顺序检查：

1. **连接器问题** → 检查连接器状态和权限
2. **构建失败** → 检查 Java 版本、Maven 配置、依赖
3. **Docker 问题** → 检查镜像名称、凭据、网络
4. **Kubernetes 问题** → 检查 kubeconfig、集群状态、资源
5. **应用问题** → 检查配置、环境变量、数据库连接
