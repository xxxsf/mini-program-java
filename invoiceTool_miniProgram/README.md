# 微信发票助手

发票管理工具微信小程序，用于发票的添加、管理、查询和发票抬头管理等功能。

## 功能

- **添加发票**：支持从微信聊天导入、本地文件导入 PDF 格式发票
- **我的发票**：查看、搜索、筛选已添加的发票列表
- **发票抬头**：管理发票抬头信息（名称、税号、地址、电话、银行信息）
- **个人中心**：个人信息管理

## 页面结构

```
pages/
  home/           首页（添加发票、我的发票入口、发票抬头管理）
  myInvoices/     我的发票列表
  addInvoice/     本地文件导入
  invoiceHeader/  发票抬头表单
  my/             个人中心 & 个人信息
  toLogin/        登录页
```

## 使用

1. 打开微信开发者工具，导入 `invoiceTool_miniProgram` 目录
2. 后端服务地址默认 `http://localhost:8080`，可在 `utils/util.js` 中修改
